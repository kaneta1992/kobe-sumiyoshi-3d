  2. ちょっとした段差が多すぎて車の操作が難しい — 車に優しい地形デザインへ調整せよ
  3. 周辺の橋を実データに基づいて架けよ。**渦森橋が最重要**

## 実装ガイド（設計は委ねるが、以下は決定事項）

1. **道路縦断の平滑化（前処理）**: RdCLに沿って地形標高をサンプル→ローパス（スプライン/移動平均）で滑らかな縦断プロファイルを生成。交差点では接続道路同士の標高を一致させる（結節点の共有標高）
2. **地形カービング（前処理）**: 道路コリドー（幅員+路肩〜1.5m）の地形をプロファイル標高へ吸着、コリドー外〜数mで元地形へスムーズにフォールオフ → ハイトマップに焼き直す。これで (a)道路と地形の段差消滅 (b)路面の細かな凹凸消滅（車に優しい）を同時に達成
3. **ドレープの縮小**: 道路メッシュはカーブ後の地形に対して+0.03〜0.05m程度に（z-fighting回避の最小限）。物理側も同じ定数を共有（現行0.32mを置き換え）
4. **橋（描画+物理）**: vt_code 2703/2713（+RdEdg 2203/2223）のセグメントは:
   - カービング対象から除外（地形は谷のまま）
   - 縦断は両端の通常部と滑らかに接続する直線/緩勾配
   - 描画: 桁（厚みのあるデッキ）・高欄（欄干）・橋台・地形との高低差が大きい箇所は等間隔の橋脚。コンクリート橋の見た目（このエリアの実橋はコンクリート道路橋）
   - 物理: デッキ上面にコライダー（走行・歩行可）。デッキ下は通り抜け可
   - **渦森橋（データ仕様に座標あり・幅員5.5-13m）を必ず目視検証対象にする**
5. 前処理の出力はアセット再生成（`npm run build:assets`）。.cache/ の既存ZIPを再利用しDL不要のはず。public/data 50MB以内維持
6. 車両サスの再調整: カービング後の路面に合わせ、サスストローク/減衰を「市街地を快適に走れる」方向へ微調整してよい
