# 契約15: 昼夜サイクル（5分/周）+ 夜間照明（街灯・プレイヤーライト・窓明かり）

ダイヤル: Opus向けゴール委譲（契約14完了後に着手）

## 目的

- 要求（ユーザー 2026-08-13）: 昼夜が5分で一周するサイクルを導入。夜は街灯とプレイヤー周辺のポイントライトを点灯。
- ゴール: 時間経過の演出でマッチに表情を出す（夕方開始→夜の決戦など）。夜の町の実在感。
- 成功条件: 5分で朝→昼→夕→夜が一周し、夜は街灯・窓明かり・プレイヤーライトで町が生きて見える。マルチプレイ全員が同じ時刻。性能予算維持。

## コンテキスト

- 必読: .claude/skills/kobe-sumiyoshi-3d-dev/SKILL.md
- 既存: src/world/sun.ts（時刻カラースクリプト7ストップ・?hour 0-24対応済み）、src/world/environment.ts（空・フォグ・影）、src/world/props.ts（電柱 — 街灯のアンカーに使える）、src/world/buildings.ts（窓 — 契約07で夜間窓明かりは任意送りになった経緯あり）、src/render/post.ts（bloom）

## 実装ガイド（設計は委ねるが、以下は決定事項）

1. **時刻の決定的導出**: `hour = (unixTime実時間 mod 300秒)/300*24`（同期メッセージ不要 — 全クライアントの壁時計で一致。数秒の時計ずれは視覚上許容）。`?hour=` 指定時は固定（デバッグ・?shotとの互換維持）。`?daylen=秒` で周期変更可（既定300）
2. **街灯**: 既存の電柱に灯具を追加（全数）。夜間（太陽高度<0）に点灯 — 描画は2層: (a) 全灯具に自照エミッシブ+ハロー（bloomで光って見える・ドローコール増ゼロに近く） (b) **プレイヤー近傍のみ実ポイントライト**（プール方式: desktop 12灯/mobile 6灯目安、近い街灯から割当・ヒステリシスでちらつき防止）。道路が実際に照らされること
3. **プレイヤーライト**: 夜間、自キャラ周辺に柔らかいポイントライト（提灯風の暖色・半径8m目安）。遠隔プレイヤー・BOTにも同様（ただし実ライトはプール内・遠方はエミッシブのみ — 夜の遠目に「誰かいる」が分かる遊びにもなる）
4. **窓明かり**: 夜間、建物の窓を決定的パターンで一部点灯（エミッシブ。契約07の任意項目を実装）。時間帯で減る（深夜は疎らに）
5. **夜の空**: 既存の月光/夜空（契約07 E39）を基盤に、星空の追加は任意。夜の影は月光1灯で控えめに
6. マッチとの整合: マッチ中も昼夜は回る（5分周期=1マッチで1周超 — 終盤が夜になる場合、気配のキラキラ・花火の視認性が上がる方向で自然に噛み合うはず。破綻があれば notes 報告）
7. 性能: mobile draw ≤100・30fps目標維持。ポイントライトプールの実測（fps影響）を報告

## エッジケース

- E104: 昼夜の境目（薄暮）で街灯・窓が段階的にフェードイン（パチッと全点灯しない）
- E105: ?hour固定時（?shot含む）はサイクル停止 — 定点スクショの再現性維持
- E106: プール割当の切替でライトが視界内で急に消えない（距離ヒステリシス+フェード）
- E107: タブ復帰時に時刻がジャンプしても照明状態が正しく追従（壁時計導出なので自然に一致するはず — 点灯状態のキャッシュ不整合に注意）
- E108: ベイクGI（昼の空可視率ベース）が夜に不自然に明るく効かない（夜は環境光変調で自然に減衰すること — 契約07の変調設計を確認）
