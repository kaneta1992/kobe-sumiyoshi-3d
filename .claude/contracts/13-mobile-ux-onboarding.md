# 契約13: モバイルUX・オンボーディング・バランス改善（ユーザー実プレイフィードバック対応）

ダイヤル: Opus向けゴール委譲。ユーザーの生フィードバック9件（2026-08-13）への対応 — 番号は下記の通り契約内で追跡すること。

## 対応項目（すべて必須。◎=特に重要）

1. ◎**モバイルUI全面改善**（「非常に使いづらい」）: スティック/ボタンのサイズ・配置・当たり判定を見直し（親指到達圏に集約・セーフエリア対応・押し間違い防止の間隔）、視点スワイプ感度の調整（+設定で変更可）、HUD情報の整理（マッチ情報は上部1行に集約・バッジは小さく）。タッチUIの表示条件バグ（マウスドラッグで出る既知事象）も修正
2. **NPCなしモード**: ロビーにホスト設定「BOT: あり/なし」（全員に同期）+ URL `?nobots`
3. ◎**回収インタラクションの明確化**（「スマホで回収方法が分からない」）: 宝箱・鍵・クレート・アイテムに近づくと統一の回収UI — PC=「E: 回収」表示、モバイル=画面下中央に大きな「回収」ボタン出現（チャンネリング対象は押している間プログレス表示）。現在の「接触で自動」は分かりにくいので明示アクションに変更してよい（自動のままにする場合も視覚フィードバック必須）
4. **POI分散**（「渦が森小近辺でイベント起こりすぎ」）: POIテーブルを拡充 — (a) bvmap **Anno レイヤーの実在注記**（施設883/887/890・公園・学校等、vt_text があるもの）を全タイルから抽出してPOI化 (b) 白鶴美術館 (135.2582, 34.7310) を追加 (c) 抽選で直近使用POIを除外し連続同一を防ぐ。**実在しない名前・座標の創作は禁止**
5. **クレジットの畳み込み**（「但し書き不要」）: 常時表示を廃止し、右下の小さな「ℹ️」→ モーダルに移動。**文言の削除は不可**（地理院出典+兵庫県CC-BY改変クレジットは法的義務 — 全文をモーダル内に保持。docs/data-spec.md §5参照）。モーダルには操作ヘルプタブも併設してよい
6. ◎**オンボーディング**（「展開がわからないままボットが勝つ」）:
   - 初回マッチ前のルール説明（3〜4枚のカード: ①宝箱を最初に開けたら勝ち ②円は縮む・外は遅くなる ③鍵を拾ってから宝箱 ④光の柱=アイテム。スキップ可・「次から表示しない」）
   - フェーズ遷移時の大きめトースト（「鍵が出現！マップ(M)で確認」等）と、**画面端の3D方向インジケータ**（現在の目標への矢印 — ステッキなしでも常時、目標種別アイコン付き）
   - BOTバランス調整: 鍵・宝箱への到達をわざと遅らせる人間優位のハンデ（例: BOTは最終安置確定から30-60秒は宝箱に向かわない・チャンネリング速度0.7倍）。「気づいたら負けてた」を排除
7. **モバイル影**: mobileプリセットに低品質の動的影を追加（プレイヤー追従の小シャドウマップ 512-1024px・近傍のみ・キャラと車に落ちる）。draw/fps予算内（30fps目標）で。既存の静的キャッシュ影と併用可
8. **スカイダイビング操作**（「↓方向が優勢すぎる」）: 自由落下中の水平操作性を強化 — WASD空中制御の加速度を上げ、前傾で水平速度が伸びる（水平:垂直 = 1:1以上まで持っていける）、落下最高速をやや抑制、傘展開後も同様に操舵可能に。降下中のカメラも見回し可能に
