## ★退屈ゼロ設計（ユーザー原則 2026-08-13: 「移動するだけの暇な時間を最小化。常に"こちらに行けば進展がありそう"を醸し出す」）

**30秒ルール（設計原則）**: プレイヤーはどの瞬間も、30秒以内に「POIへの到着 / 新しい手がかりの取得 / 行き先の意思決定」のどれかが起きる状態を保つ。実装は以下の組み合わせ:

1. **常時2つ以上のリード（手がかり）を可視化**: 画面内・ミニマップに、必ず2つ以上の「行く理由」が見えている状態を維持（光の柱・花火・補給機・ステッキの指す方角など）。リードが1つ以下になったらイベントを前倒しで発火させるディレクター制御
2. **ルートビーコン（光の柱）**: アイテム群の湧き場所（コープ前・小学校・公園などの実在POI）に遠くから見える光の柱。近づくと消灯し「取られた/取った」が分かる
3. **道中の小拾い（ブレッドクラム）**: 道路沿いにコイン状の小アイテム列を決定的配置。拾うとスタミナ/ダッシュ微強化。コイン列はPOIへ誘導する形に敷く（マリオのコイン誘導と同じ文法）
4. **定期イベント（45〜60秒周期でどれかが起きる）**:
   - 補給機の飛来 → 物資クレート投下（光の柱+パラシュート、良アイテム確定）
   - 宝箱の花火（位置がチラ見え → 全員の足が動く）
   - イノシシの群れの通過（騎乗チャンス）
   - 安置収縮予告（次の円がミニマップに出る = 移動の意思決定）
5. **宝箱の段階開示**: 安置フェーズごとに宝箱の手がかりが段階的に開く（第1収縮=四半区画のヒント → 第2=地図の円 → 最終=花火で可視化）。「探す範囲」が常に今の行動半径に釣り合う
6. **移動そのものを遊びに**: 下り坂ブースト・滑空・ジャンプ・イノシシ騎乗・バス停ワープ — 「移動手段の選択」自体が楽しい意思決定になる
7. **実況アナウンス**: 「千丈谷方面で花火の目撃情報！」のようなテキスト実況で方向性を演出（ローカル地名の読み上げが地元ネタ側の楽しさも担う）

## ★採用済みの追加要素（旧◆提案 — 2026-08-13 全部採用）

1. ★**鍵と宝箱の分離**: 宝箱を開けるには「鍵」が必要。鍵は中盤に別の場所（安置外周寄り）に湧く → 最終盤の「中心で待ち構えるだけ」を防ぎ、動きが生まれる
2. **回収チャンネリング**: 宝箱の回収に10秒の詠唱。他プレイヤーの「体当たり（ショルダータックル）」で中断できる → 戦闘なしでも最終安置に攻防が生まれる（ポップな世界観と整合）
3. **宝箱の気配演出**: 近づくと音が鳴る/一定間隔で宝箱から花火が上がる → 「あそこだ！」の全員ダッシュが起きる
4. **偽宝箱（ミミック）**: 開けるとイノシシが飛び出す等のハズレ。リスクとリターン
5. **下り坂ブースト**: 坂を走り降りると加速 — この町の急坂が全部「楽しい滑り台」になる
6. **最終安置の抽選テーブル**: 展望台公園・渦が森小の校庭・千丈谷・コープ前など実在ランドマークに偏らせる → 「今日は校庭決戦だ」のようなローカル会話が生まれる
7. **勝利演出とリマッチ**: 勝者の頭上に花火+全員のリザルト表示 → ワンタップでリマッチ投票

## 技術方針（P2P前提の骨子 — 実装契約時に詳細化）

- **決定的シード + ホスト選出**: ルーム参加者の最小ピアIDがホスト。マッチシード（宝箱・アイテム・乗り物配置、安置の中心列）はシードから決定的に生成 — 全員が同じ配置を再現でき、同期は「マッチ開始時刻+シード」だけで済む
- **安置収縮**: シードから決まる中心列+半径スケジュール。3D表示は円柱状の壁シェーダー、ミニマップにも円表示
- **BOT**: ホストが思考を実行し、既存のプレイヤー同期形式（state）で配信 — 遠隔プレイヤーと同じ経路で描画される。ナビゲーションは既存のRdCL道路グラフを流用
- **宝箱回収の裁定**: 回収完了はホストが裁定（同時回収の競合解決）。ホスト離脱時は次点ピアが継承
- **ヘリコプター**: アーケード風の簡易飛行物理（リフト・ピッチ/ロール・ヨー）。着陸判定は緩く
- **スカイダイビング**: 輸送機はシードで決まる直線経路。降下=自由落下+傘/マントで減速着地
- 既存資産の流用: ミニマップ（契約09）が安置表示の土台 / スーパーマンモード（契約06）が飛行・滑空の物理土台 / 車（契約04）はそのまま
