# データ仕様（凍結） — 神戸・住吉山手 3D街歩き

最終更新: 2026-08-12（メインが疎通確認済み。ここに書かれたURL・数式は実測検証済み — 探し直さないこと）

## 1. 対象エリアと座標系

- **ワールド原点**: 兵庫県神戸市東灘区住吉山手九丁目11番 = **lon0 = 135.252243, lat0 = 34.740726**（地理院ジオコーダで確定済み）
- 参考ランドマーク: 市立渦が森小学校 = (135.2503338, 34.7389573)。渦森台・展望台公園は原点の北西〜北、千丈谷は北東の谷筋。
- **エリア範囲**: 原点中心の正方形 **2400m × 2400m**（半径1200m）
  - 度換算: dLat = ±1200/111132 ≈ ±0.010798, dLon = ±1200/(111320·cos(lat0)) ≈ ±0.013122
- **ローカル座標系（three.js）**: 右手系・Y-up・単位メートル
  - `x = (lon - lon0) * 111320 * cos(lat0·π/180)` （東 = +x）
  - `z = -(lat - lat0) * 111132` （北 = -z）
  - `y = 標高[m]`（ジオイド・楕円体差は無視。プロトタイプ精度で十分）
- このエリアは六甲山麓の急斜面。標高はおよそ 50m（南端）〜 450m超（北端の山地）。**垂直方向のレンジが大きいことを前提にする**（カメラfar、フォグ、物理の落下判定など）

## 2. 地形（標高）

- **地理院標高タイル DEM5A**: `https://cyberjapandata.gsi.go.jp/xyz/dem5a_png/{z}/{x}/{y}.png`、**z=15 を使用**（5m解像度）
  - 実測確認済み: `15/28694/13008.png` → 200 OK（対象エリア中心）
- **デコード式**（PNG RGB → 標高メートル）:
  - `v = R*65536 + G*256 + B`
  - `v == 8388608 (2^23)` → **無効値**（近傍補間 or 0m とする）
  - `v > 8388608` → `v -= 16777216 (2^24)`
  - `h = v * 0.01` [m]
- **フォールバック**: タイル404または無効値領域は 10mメッシュ `dem_png`（z=14）で補う: `https://cyberjapandata.gsi.go.jp/xyz/dem_png/{z}/{x}/{y}.png`（同じデコード式）
- CORS: `Access-Control-Allow-Origin: *` 確認済み

## 3. 地表テクスチャ（航空写真）

- **全国最新写真（シームレス）**: `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`、**z=17 を使用**（約1.2m/px）
  - 実測確認済み: `17/114779/52032.jpg` → 200 OK。**拡張子は .jpg（.pngは404）**
- エリア全体をキャンバスに合成して1枚（または数枚）の大テクスチャにする想定（z17でエリア全体 ≈ 8×8タイル）

## 4. 建物・道路・水域（ベクトルタイル）

- **国土地理院 最適化ベクトルタイル**: `https://cyberjapandata.gsi.go.jp/xyz/optimal_bvmap-v1/{z}/{x}/{y}.pbf`、**z=16 を使用**
  - 実測確認済み: `16/57389/26016.pbf` → 200 OK（38KB）、CORS `*`
- 形式: Mapbox Vector Tile。デコードは `@mapbox/vector-tile` + `pbf`
  - **注意（実測）: pbf の最新版（v5系）は `PbfReader` を named export する**（`import { PbfReader } from 'pbf'`）。`new VectorTile(new PbfReader(arrayBuffer))`。v3系なら default export の `Pbf`。ハマったらバージョンを固定して回避してよい
- **使用レイヤーと実測済み属性**:
  - `BldA`（建物ポリゴン）: `vt_code`: **3101=普通建物, 3102=堅ろう建物, 3111=普通無壁舎**（1タイルで517件を確認 — データ密度は十分）
  - `RdCL`（道路中心線）: `vt_code`: 2701=市区町村道等ほか, 属性 `vt_rnkwidth`（例 "3m-5.5m未満"）, `vt_width`, `vt_motorway`
  - `RdEdg`（道路縁）: 2201等 — 道路ポリゴン化に使える（任意）
  - `Cntr`（等高線, `vt_alti`）, `WA`（水域 5200）, `WL`（水涯線）: 任意
- **橋・高架部（2026-08-13 実測確認）**: RdCL `vt_code` の下1桁が3のもの = 橋・高架部（**2703**=通常道路の橋 9件、**2713**=軽車道の橋 1件をエリア内で確認。2701/2711/2721/2731が通常部）。RdEdg側は **2203**（41件）/2223 が橋の道路縁。橋名注記はz16のAnnoに無し
  - **渦森橋**: (135.25301, 34.739446) 付近の vt_rnkwidth "5.5m-13m未満" の2703セグメント — 市バス38系統（赤塚橋→渦森橋→渦森台）の経路と整合 [Web裏取り済み]。最重要の目視検証対象
- **建物高さのヒューリスティック**（bvmapに高さ属性は無い）:
  - 3101 普通建物: 2階相当 5〜8m
  - 3102 堅ろう建物: 12〜30m（フットプリント面積が大きいほど高く）
  - 3111 無壁舎: 3m
  - **乱数はポリゴン座標由来の決定的ハッシュでシードすること**（マルチプレイで全クライアントが同じ町を見るため。Math.random()禁止）
- タイル境界で建物ポリゴンが分割されている場合がある — プロトでは分割のまま許容（重複押し出しの見た目劣化は許容範囲）

  - DEM: `https://gic-hyogo.s3.ap-northeast-1.amazonaws.com/2022/Vectortile2026/dem/{z}/{x}/{y}.pbf`
